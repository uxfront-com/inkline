Recipes let you style your own components the way Inkline styles its own. Each one is a
Styleframe recipe for one component: a single call adds the component's base styles, its
colors, variants and sizes, and the compound variants that combine them. You get back a
type-safe function that returns the class names for a set of props, so you can put them on
any markup, in any framework.

## Install

```bash
npm install -D @inkline/theme
```

The recipes reference the design tokens that `@styleframe/theme` defines, so every page sets
up `styleframe.config.ts` with `useDesignTokensPreset()` and `useUtilitiesPreset()` from
`@styleframe/theme`, and registers the recipe in the component's own styleframe file.

## Usage

Register the recipe in the component's styleframe file:

```ts [src/components/badge.styleframe.ts]
import { styleframe } from "virtual:styleframe";
import { useBadgeRecipe } from "@inkline/theme";

const s = styleframe();

const badge = useBadgeRecipe(s);

export default s;
```

Then import its runtime function from the virtual module and pass it the props:

```ts [src/components/badge.ts]
import { badge } from "virtual:styleframe";

const classes = badge({ color: "neutral", variant: "solid", size: "sm" });
// → "badge _background:neutral _color:white _padding:xs ..."
```

## Write your own recipe

Most pages show how to override a recipe's defaults. When no recipe fits, you can write your
own with Styleframe's `recipe()` function: [Recipes](https://styleframe.dev/docs/api/recipes)
in the Styleframe docs walks you through it.
